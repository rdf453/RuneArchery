☀️ 제1 묶음: 프레이야의 아에티르 (풍요와 기초 에너지)
자연계의 기본적인 물질, 힘, 그리고 삶의 시작을 나타냅니다.
• ᚠ — Fehu (페후)
	• 뜻: 가축 (Cattle) 재물, 풍요
	• 상징: 가축이 곧 자산이던 시절의 부, 풍요, 움직이는 재산, 시작되는 에너지
• ᚢ — Uruz (우루즈)
	• 뜻: 오록스 (야생 소, Aurochs)강인함, 원초적 힘
	• 상징: 야생 소의 거친 힘, 물리적인 에너지, 생명력, 날것의 용기 야성적인 체력, 순수한 물리적 힘, 굴하지 않는 의지
• ᚦ — Thurisaz (투리사즈)
	• 뜻: 거인 / 가시 (Giant / Thorn) 거인, 가시, 망치(토르의 가시)
	• 상징: 적을 찌르는 가시나 파괴적인 거인, 저항, 방어, 갈등, 강력한 위력 파괴적인 방어, 유해한 것으로부터의 보호, 공격적인 힘
• ᚨ — Ansuz (안수즈)
	• 뜻: 신 / 입 (God / Mouth) 아스가르드의 신(오딘), 전령, 지혜/소통
	• 상징: 주신 오딘의 계시, 지혜, 의사소통, 영감, 주문, 말의 힘 신성한 영감, 주문, 언어, 지혜
• ᚱ — Raidho (라이도)
	• 뜻: 전차 / 여정 (Chariot / Journey) 마차, 여정, 이동, 질서
	• 상징: 바퀴의 구름, 이동, 여행, 방향성, 질서와 리듬 길을 따라가는 움직임, 순탄한 여행, 제어된 방향성
• ᚲ — Kenaz (케나즈)
	• 뜻: 횃불 (Torch) 횃불, 불꽃, 지식/의지
	• 상징: 어둠을 밝히는 불꽃, 기술, 지식, 창조성, 열정, 통찰력 어둠을 밝히는 불꽃, 열정, 창조적인 지혜
• ᚷ — Gebo (게보)
	• 뜻: 선물 (Gift) 선물, 계약, 균형, 동반
	• 상징: 신과 인간, 혹은 인간 사이의 주고받음, 동맹, 결속, 희생, 조화 Give & Take, 동등한 교환, 관계 형성.
• ᚹ — Wunjo (운조) 
	• 뜻: 기쁨 (Joy)기쁨, 희열, 조화
	• 상징: 고통 뒤에 오는 만족, 영광, 성공, 조화, 편안함 시련 후 찾아오는 평화, 완벽한 만족, 긍정적 에너지.
