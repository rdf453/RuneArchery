🌨️ 제2 묶음: 헤임달의 아에티르 (시련과 외부 세계)
인간이 통제할 수 없는 자연의 역경, 환경의 변화, 정신적 시련을 나타냅니다.
• ᚺ — Hagalaz (하갈라즈)
	• 뜻: 우박 (Hail)
	• 상징: 하늘에서 떨어지는 얼음 파편, 예기치 못한 재앙, 파괴, 변화를 위한 붕괴
• ᚾ — Nauthiz (나우디즈)
	• 뜻: 결핍 / 필요 (Need / Distress)
	• 상징: 끈기로 버텨야 하는 궁핍함, 구속, 인내, 생존 의지, 운명적 한계
• ᛁ — Isa (이사)
	• 뜻: 얼음 (Ice)
	• 상징: 모든 것을 얼리는 추위, 정지, 정체, 차가움, 보존, 감정의 억제
• ᛃ — Jera (예라)
	• 뜻: 수확 / 1년 (Year / Harvest)
	• 상징: 시간이 흘러 얻는 결실, 인과응보, 주기적인 반복, 노력의 대가
• ᛇ — Eihwaz (이와즈)
	• 뜻: 주목나무 (Yew)
	• 상징: 활의 재료이자 사시사철 푸른 나무, 삶과 죽음의 순환, 인내, 유연함, 영생
• ᛈ — Perthro (페르트로)
	• 뜻: 주사위 통 / 비밀 (Dice cup / Secret)
	• 상징: 무엇이 나올지 모르는 주사위 컵, 운명, 확률, 비밀, 미지의 가능성
• ᛉ — Algiz (알기즈)
	• 뜻: 엘크 / 보호 (Elk / Protection)
	• 상징: 맹수를 막아주는 엘크의 뿔, 방어, 장벽, 수호, 영적인 보호
• ᛊ — Sowilo (소윌로)
	• 뜻: 태양 (Sun)
	• 상징: 어둠을 몰아내는 빛, 승리, 명예, 생명력, 치유, 완전한 성공
