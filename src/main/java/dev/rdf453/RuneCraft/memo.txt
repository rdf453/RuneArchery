 룬의 티어 (얘도 룬크래프트로 넘겨야 할듯)
    Divine 티어 룬에 대하여
        각자 룬마다의 자격 증명을 넣어 자격 미달인 자가 사용시 거부반응(반동 정도로 생각하면 될듯) 
        또는 자격 증면(게보: 젤다 마스터소드 마냥 일정 체력 요구?) 
        또는 매우 약화(소윌로를 예로들면 단순히 아침으로 만든다 정도의)
        등으로 차별화
        이 티어의 룬을 사용하기 위해선 신성이 필수불가결 

        충분한 신성을 지녀 신으로서 거듭 났을때 디바인 룬들은 진정한 모습을 드러내어  사용시 하나의 무구로서 거듭남
        자격 증명: 극히 단순하게  묘사하여 신성 수치작

    Spiriual 티어 룬에 대하여
        이쯤 되면 슬슬 세계에 대하여 큰 영향을 끼치기 시작 
        영혼 수치가 0 이하로 떨어졌을때 사망할시 명계로 추방 되며 다가즈의 자격 증명 외 환생 의식을 거치지 않는 이상 탈출 불가

    Mental 티어 룬에 대하여
        여기 이상부터는 숨겨진 스탯으로 관리 
        멘탈은 마나의 회복에 관여 하며 멘탈 수치가 0이 되면 정신붕괴 디버프에 걸리며 일정 시간동안 멘탈을 회복 하지 않을시 (플레이스 홀더 디메리트 필요)


    Physical 티어 룬에 대하여
        단순히 물질에 대하여 영향을 끼침

    1. 룬 4단계 위계 (Tier) 및 기본 마나
    --------------------------------------------------
    - 1단계: 물질 (PHYSICAL)  | 기본 마나: 10
    - 개념: 육체, 도구, 자원, 이동, 물리적 현상
    - 2단계: 정신 (MENTAL)    | 기본 마나: 20
    - 개념: 지혜, 감정, 이성, 사회, 인간적 조화
    - 3단계: 영혼 (SPIRITUAL) | 기본 마나: 35
    - 개념: 운명, 죽음, 세계수, 인과, 수호
    - 4단계: 신성 (DIVINE)    | 기본 마나: 50
    - 개념: 신(아스가르드), 태양, 계약, 우주적 법칙


    2. 24개 룬 위계별 매핑표
    --------------------------------------------------
    [1단계: 물질 (PHYSICAL) - 기본 마나 10]
    - Fehu (ᚠ)    : 재물 / 가축 / 기본 자원
    - Uruz (ᚢ)    : 야생소 / 육체적 힘
    - Raidho (ᚱ)  : 마차 / 물리적 이동
    - Kenaz (ᚲ)   : 횃불 / 불꽃 / 빛
    - Jera (ᛃ)    : 수확 / 물리적 결실
    - Ehwaz (ᛖ)   : 말 / 수송 / 협력

    [2단계: 정신 (MENTAL) - 기본 마나 20]

    - Nauthiz (ᚾ) : 결핍 / 인내
    - Isa (ᛁ)    : 얼음 / 정지 / 동결
    - Berkano (ᛒ): 자작나무 / 성장 / 치유
    - Mannaz (ᛗ) : 인간 / 지능 / 자아
    - Laguz (ᛚ)   : 물 / 직관 / 감정

    [3단계: 영혼 (SPIRITUAL) - 기본 마나 35]

    - Hagalaz (ᚺ) : 우박 / 운명적 시련

    - Perthro (ᛈ) : 운명 / 비밀 / 확률
    - Algiz (ᛉ)   : 영적 수호 / 수호령
    - Othala (ᛟ)  : 혈통 / 영토 / 조상

    [4단계: 신성 (DIVINE) - 기본 마나 50]
    - Ansuz (ᚨ)   : 오딘 / 신성한 언어

    - Ingwaz (ᛝ)  : 프레이 / 신성한 씨앗
