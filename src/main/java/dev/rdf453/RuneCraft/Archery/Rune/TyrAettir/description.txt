⚔️ 제3 묶음: 티르의 아에티르 (신성과 인간의 질서)
법률, 정의, 사회적 관계, 그리고 내면의 완성도를 나타냅니다.
• ᛏ — Tiwaz (티와즈)
	• 뜻: 전쟁의 신 티르 (Tyr)
	• 상징: 승리와 정의를 위한 칼날, 명예, 대의를 위한 희생, 규율, 리더십
• ᛒ — Berkano (베르카노)
	• 뜻: 자작나무 (Birch)
	• 상징: 봄에 가장 먼저 싹트는 나무, 탄생, 성장의 에너지, 치유, 어머니의 품
• ᛖ — Ehwaz (에와즈)
	• 뜻: 말 (Horse)
	• 상징: 기사와 말의 유대감, 파트너십, 신뢰, 협동, 빠른 진전
• ᛗ — Mannaz (마나즈)
	• 뜻: 인간 (Man)
	• 상징: 공동체 속의 개인, 자아 정체성, 인류애, 협력, 사회적 의무
• ᛚ — Laguz (라구즈)
	• 뜻: 물 / 바다 (Water / Ocean)
	• 상징: 끊임없이 흐르고 깊이를 알 수 없는 바다, 직관, 감정, 무의식, 흐름
• ᛜ — Ingwaz (인구즈)
	• 뜻: 대지의 신 잉그 / 씨앗 (Seed)
	• 상징: 땅속에 묻힌 씨앗, 잠재력, 내부의 성숙, 휴식기, 가두어진 에너지
• ᛞ — Dagaz (다가즈)
	• 뜻: 낮 / 새벽 (Day)
	• 상징: 밤이 끝나고 찾아오는 아침, 각성, 새로운 시작, 명확함, 완전한 전환
• ᛟ — Othala (오달라)
	• 뜻: 고향 / 유산 (Heritage / Estate)
	• 상징: 조상으로부터 물려받은 땅, 가문, 전통, 영속성, 귀환
