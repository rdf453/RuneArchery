☀️ 제1 묶음: 프레이야의 아에티르 (풍요와 기초 에너지)
자연계의 기본적인 물질, 힘, 그리고 삶의 시작을 나타냅니다.
• ᚠ — Fehu (페후)
	• 뜻: 가축 (Cattle)
	• 상징: 가축이 곧 자산이던 시절의 부, 풍요, 움직이는 재산, 시작되는 에너지
• ᚢ — Uruz (우루즈)
	• 뜻: 오록스 (야생 소, Aurochs)
	• 상징: 야생 소의 거친 힘, 물리적인 에너지, 생명력, 날것의 용기
• ᚦ — Thurisaz (투리사즈)
	• 뜻: 거인 / 가시 (Giant / Thorn)
	• 상징: 적을 찌르는 가시나 파괴적인 거인, 저항, 방어, 갈등, 강력한 위력
• ᚨ — Ansuz (안수즈)
	• 뜻: 신 / 입 (God / Mouth)
	• 상징: 주신 오딘의 계시, 지혜, 의사소통, 영감, 주문, 말의 힘
• ᚱ — Raidho (라이도)
	• 뜻: 전차 / 여정 (Chariot / Journey)
	• 상징: 바퀴의 구름, 이동, 여행, 방향성, 질서와 리듬
• ᚲ — Kenaz (케나즈)
	• 뜻: 횃불 (Torch)
	• 상징: 어둠을 밝히는 불꽃, 기술, 지식, 창조성, 열정, 통찰력
• ᚷ — Gebo (게보)
	• 뜻: 선물 (Gift)
	• 상징: 신과 인간, 혹은 인간 사이의 주고받음, 동맹, 결속, 희생, 조화
• ᚹ — Wunjo (운조)
	• 뜻: 기쁨 (Joy)
	• 상징: 고통 뒤에 오는 만족, 영광, 성공, 조화, 편안함
